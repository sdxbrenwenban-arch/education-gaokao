# 中国高考状元数据库（2000–2026 为主，最早 1956）

**版本 v1.0（2026-08-09）** · 30 省级行政区 · 2598 条记录

## 一、项目背景

本数据库系统收录中国省级高考状元（含文理科、新高考物理/历史类、外语类、汉语言、单列类等轨道的并列状元及部分榜眼/探花），覆盖 30 个省级行政区（不含港澳台与西藏，西藏因考生数量少且情况特殊未纳入）。时间跨度 1956–2026，其中 2000–2026 覆盖完整度最高。

用途：教育经济学研究（榜样效应、排名可见度、性别差异、高考制度变迁等）。

## 四、分数制度口径（跨省比较前必读）

| 时期/省份 | 制度 | 满分 |
|---|---|---|
| 河南 1994–2000、山东 1996–2000、海南全期 | 标准分制 | 900（海南 2013 起含会考加成，可超 900） |
| 浙江 2009–2016 | 3+X+自选模块 | 810 |
| 江苏 2008–2020 | 语数外+附加题+选测等级 | 480 |
| 江苏 2002–2007 | 3+X大综合 | 750（不分文理） |
| 上海 2017 起 | 3+3（选考赋分） | 660 |
| 上海 2017 前 | 3+1+综合 | 630 上下（各期不同） |
| 广东 2007–2009 | 3+X+文/理基础 | 750（基础150+X科150） |
| 云南 2019 起 | 3+X+量化成绩 | 772（量化22） |
| 内蒙古 | 全国卷+外语半分 | 750（外语含半分） |
| 其余省份/时期 | 全国卷/自主命题 | 750 |
| 早期（1980s） | 各科100分制 | 500–710 不等（逐年改革） |

**结论：合并跨省分数前必须按省-年标准化（如省-年-轨道内 Z-score）。**

## 五、性别字段说明

- 确认方式：① 原文/报道代词（"她/他"）② 官方档案（如教育在线"性别：男"）③ 数据驱动姓名特征初筛（回测：可判者中女 91.4% / 男 88.7%，note 标注"初筛确认"）④ 少数民族名（如维吾尔名 Adil 为男）
- `NA`（约 39%）构成：2000 年前记录（媒体报道无代词）、中性名（2000 后亦无报道代词）、匿名记录（禁炒期"某同学"）
- **使用建议**：主分析建议仅用 gender 已确认样本（60.7%），或对 NA 做稳健性

## 六、已知局限

1. 2000 年前部分省份年份缺失（媒体报道缺失）
2. 2018 年后多省禁止炒作：2021 起北京/天津等以"据称/存疑/匿名"为主（note 已标注可信度）
3. 少数民族双轨省份（新疆单列类/普通类、吉林汉语言）口径复杂，分析需分轨道
4. 高考移民/借读现象（青海 18 条外省籍贯）可能污染"学校-省份"关联
5. 西藏未纳入（数量少、情况特殊）

## 九、制度面板（制度面板_省年.csv）

30 省 × 2000–2026 = 810 行。字段：

| 字段 | 说明 |
|---|---|
| exam_mode | 高考模式：3+2 / 3+X文理综 / 大综合(不分科) / 3+X自选(浙) / 3+X基础(粤) / 3+X量化(滇) / 3+3 / 3+1+2 / 标准分 |
| score_system | std900 / nat750 / zj810 / js480 / sh660 / yn772 / gd_base750 |
| full_score | 满分（分数标准化用） |
| track_split | 文理 / 不分 / 物历（3+1+2）/ 3+3不分 |
| ban_stage | 禁炒阶段：0=宽松(<2005) 1=收紧(2005–2017) 2=严控(2018+) |
| n_records / n_ties / n_bonus_flagged / n_gender_confirmed / n_anonymized | 主库派生：记录数/并列数/含加分数/性别确认数/匿名数 |

匿名化起始年（可见度断点）：青海 2018（最早）、北京 2021、内蒙古 2023、重庆/新疆 2024、天津/辽宁/陕西/宁夏 2026。
