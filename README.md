# 教育高考研究：中国高考状元数据库（Education & Gaokao）

本仓库包含中国高考状元数据库 v1.0 及配套研究文档。

## 内容

| 目录 | 内容 |
|---|---|
| `数据/` | 发布版数据库（30 省 2598 条）、制度面板、性别初筛结果、母校-年面板、README 与采集日志 |
| `论文/` | 论文初稿（v1.0，Markdown/HTML）、两轮评审报告、H3 母校学妹效应采集方案、核验报告 |
| `图表/` | 女生登顶率趋势图（含上下界区间）、理科省际差异图 |

## 核心数据

- **gaokao_top_scorer_2026.csv**：30 省、2598 条状元记录（1956–2026），字段含省份/年份/轨道/脱敏姓名/性别/分数/学校/并列/加分/录取院校；姓名已匿名化（首字+*）
- **制度面板_省年.csv**：30 省 × 2000–2026，高考模式、分数制、禁炒阶段
- **性别初筛结果.csv**：数据驱动姓名特征初筛（回测可判者中女 91.4%/男 88.7%）

## 论文

《中国高考状元性别分布的描述性证据：基于 30 省 2598 条记录的新数据库（2000–2026）》——数据与描述性事实定位，核心发现：文理登顶率 2:1 分化（上下界口径稳健）、省际逾 10 倍悬殊、清北集中 61.4%、禁炒令匿名化时间线。
