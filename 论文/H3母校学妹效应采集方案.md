# H3 母校学妹效应 — 数据采集方案 v1

**定位**：主分析转向"状元母校学妹效应"（保留原文"身边榜样"机制的最直接继承），新疆双轨 28 对作为辅助识别。

## 一、研究设计

| 要素 | 设计 |
|---|---|
| 样本 | 2004–2024 年各省状元母校（超级中学），学校-年观测 |
| 处理 | 当年状元为女（校友榜样为女性） |
| 结果变量 | 次年母校女生清北录取数（分性别可得时）、清北总数、高分段（600+）人数、次年再出状元概率 |
| 识别 | 学校固定效应 + 状元性别 + 学校线性趋势（学校内部跨年比较） |
| 安慰剂 | 非状元母校同年表现；假状元性别（滞后一期） |

## 二、数据需求（三张表）

### 表 1：母校-年面板（school_year）
从主库派生：province, school, year, track, 状元性别, 状元分数, 状元是否复读/移民

### 表 2：喜报结果（school_news）
- 来源：学校官网"高考喜报"、公众号、媒体报道（"XX 中学 2025 年高考喜报"）
- 字段：school, year, 清北录取总数, 清北女生数（可得时）, 600+ 人数, 一本率（可得时）, 来源 URL
- 覆盖目标：超级中学（出过状元/清北 30+ 的学校）优先

### 表 3：对照校（可选）
- 未出状元但规模相近的学校（同市同梯队），用于安慰剂

## 三、采集优先级（按可得性与价值）

| 优先级 | 学校类型 | 说明 |
|---|---|---|
| P0 | 高频状元母校（≥3 次：衡水中学、成都七中、西安高新一中、银川一中、湟川中学、镇海中学、贵阳一中、乌鲁木齐一中、合肥一六八、呼和浩特二中、临川一中、哈尔滨三中等约 40 所） | 每校 10–20 年喜报，构成面板主体 |
| P1 | 双状元/并列学校 | 补并列样本 |
| P2 | 单次状元母校 | 样本补充 |

## 四、可行性评估（基于试点经验）

| 项目 | 评估 |
|---|---|
| 喜报可得性 | 高——超级中学官网/公众号年年发喜报，"清北人数"是核心指标 |
| 分性别可得性 | 中——约 30–50% 喜报列出女生录取明细（"王XX 同学录取北大"清单可判性别） |
| 2018 后禁炒影响 | 中——学校喜报不受"禁炒状元"约束（学校宣传自身办学成果），反而更依赖喜报传播 |
| 主要成本 | 每校需逐年检索+抓取，约 40 校 × 15 年 = 600 校年（可分批） |

## 五、与原文的对话

原文（班级）：第一名性别 → 同班女生成绩 +0.403σ
本文（母校）：女状元 → 同校学妹次年清北录取/高分段
- 机制同一：身份接近的榜样（校友 vs 同班）
- 可见度不同：校庆/表彰大会/喜报传播（介于人际与媒体之间）
- 预期效应排序：同班 > 同校 > 全省（与 H3 距离衰减一致）

## 六、执行步骤

1. 从主库生成 school_year 面板（含 40 所 P0 学校清单）
2. 逐校检索"XX中学 + 年份 + 高考喜报"（web_search → curl/open-link 抓取）
3. 提取清北人数/女生数/高分段 → 填表 school_news
4. 面板合并 → 学校FE 回归
5. 稳健性：非状元母校安慰剂、状元性别滞后、禁炒前后分组

## 七、产出

- school_year.csv（母校-年面板）
- school_news.csv（喜报结果，分批填充）
- 回归结果 + 报告
